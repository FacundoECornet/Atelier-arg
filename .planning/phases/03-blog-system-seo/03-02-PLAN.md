## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Information Disclosure | BlogList.jsx, BlogArticle.jsx | mitigate | Both components query with where('publicado', '==', true). Draft articles (publicado=false) never returned in public queries. No admin-only fields leak to public. |
| T-03-05 | Tampering | BlogArticle.jsx slug param | mitigate | Slug parameter stripped of trailing slash (replace(/\/$/, '')). Firestore where('slug', '==', sanitizedSlug) prevents injection. No shell command execution, no eval. Slugify in admin create ensures only [a-z0-9-] chars reach Firestore. |
| T-03-06 | Information Disclosure | BlogArticle.jsx dangerouslySetInnerHTML | mitigate | Content sourced from react-quill which sanitizes HTML output (T-03-01). No user-submitted content reaches dangerouslySetInnerHTML without Quill sanitization. If Fran pastes raw HTML, react-quill strips dangerous tags. |
</threat_model>
