## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding in admin fields |
| sm | 8px | Gap between label and input, compact spacing |
| md | 16px | Default element spacing, card padding (p-4) |
| lg | 24px | Section padding (p-6 sm:p-8), gap between cards |
| xl | 32px | Layout gaps, container padding (px-8) |
| 2xl | 48px | Major section breaks (py-12), hero sections |
| 3xl | 64px | Page-level spacing (py-16) |

Exceptions: none — existing Tailwind default patterns cover all blog components.

**Source:** Codebase patterns in Noticias.jsx, propiedadesCards.jsx, PropiedadesInfo.jsx, AdminForm.jsx.

**Source:** Codebase patterns across all components.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (white) | Page backgrounds, section backgrounds, card backgrounds |
| Secondary (30%) | `#f9fafb` (gray-50) | Alternate section backgrounds, property detail page bg |
| Accent (10%) | `#000000` (black) | Primary action buttons, CTAs, focus ring outlines |
| Destructive | `#ef4444` (red-500) | Error text, required field asterisks, article not found |

**Surface hierarchy:**
- Page background: white → sections overlay white on white
- Card containers: bg-white, border-gray-200, shadow-xl / shadow-lg
- Default text: text-black (headings), text-gray-600/700/800 (body)
- Hero overlay: gradient black/40 to black/60 over image

**Accent reserved for:**
- Primary action buttons ("Ver más", "Ver todas las novedades →")
- Admin "Guardar" button (bg-black text-white rounded-xl)
- Back button ("← Volver al blog") — bg-gray-900 or bg-black
- Focus ring outlines (`focus:ring-black`)
- Active navigation states
- Toggle switch active state (BooleanField "Publicado")
- Loading skeleton pulse animation

**NOT accent:** Secondary buttons, card borders, dividers, labels, description text, empty state text.

**Source:** Codebase — all existing components use this scheme consistently.

## Developer Notes

- **All new components in `.jsx`** — no TypeScript (project convention)
- **Arrow function components** — `const Component = () => { ... }` (project convention)
- **Explicit React import** — `import React from 'react'` in every JSX file
- **Spanish UI** — all labels, copy, error messages in Spanish
- **Tailwind only** — no styled-components, no `<style jsx>` blocks
- **react-quill** — added to admin form only, lazy-loaded via admin route (not in public bundle)
- **react-helmet-async** — HelmetProvider at App.jsx root wrapping Shell
- **Postbuild script** — generates static HTML in `dist/blog/:slug/index.html` (not UI, but affects how crawlers see content)
