<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Firebase Auth | Credentials (email/password) sent to Google identity servers — Firebase SDK handles transport security |
| Browser → Firestore | Data reads/writes cross trust boundary — Firestore rules enforce authorization (Phase 02-02) |
| Client code → Browser | Auth state (`user` object) stored in React context — not in localStorage, not spoofable |
| Build time → Client bundle | Env vars injected at build — values visible in client JS (by design, not secrets) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | AuthContext/AuthGuard | mitigate | Use `onAuthStateChanged` from Firebase SDK — never check localStorage or cookies. Firebase SDK verifies tokens with Google servers. |
| T-02-02 | Spoofing | LoginPage | mitigate | Use `signInWithEmailAndPassword` from Firebase SDK — credentials sent over HTTPS to Google auth servers. No custom auth logic. |
| T-02-03 | Information Disclosure | Firebase.js / .env | accept | VITE_ prefixed env vars are embedded in client JS bundle at build time. Firebase config values are not secrets — they identify the project to Firebase SDK. The actual security is in Firestore rules (02-02) and Firebase Auth (server-side). |
| T-02-04 | Elevation of Privilege | AuthGuard bypass | mitigate | AuthGuard wraps admin route element in App.jsx — cannot be bypassed via URL manipulation (checked on every render, not just on mount). `replace: true` on Navigate prevents back-button from reaching admin after logout. |
| T-02-05 | Denial of Service | LoginPage | accept | Rate limiting handled by Firebase Auth (server-side). Login form has submitting state to prevent double-submit. No custom rate limiting needed. |
| T-02-06 | Tampering | Build env vars | mitigate | Startup validation loop throws clear error listing missing vars — prevents deploy with broken config. Build fails fast rather than producing broken JS. |
</threat_model>
