Implement D-01 (per CONTEXT.md):

1. **vite.config.js:** Change `base: './'` to `base: '/'`. BrowserRouter requires absolute base for clean URLs — relative base breaks deep-link asset resolution at paths like `/propiedades/abc123`.

2. **src/App.jsx:**
   - Change line 2 import: `HashRouter as Router` → `BrowserRouter as Router`
   - Add old-hash redirect logic (D-03): In the `Shell` component (which already uses `useLocation`), add a `useEffect` that detects `window.location.hash` matching old `/#/` pattern and redirects to clean path via `navigate()`. Import `useNavigate` from react-router-dom (not yet imported in Shell — only `useLocation` is imported currently).
   - Pattern: `useEffect(() => { const hash = window.location.hash; if (hash && hash.startsWith('#/')) { const clean = hash.replace(/^#/, ''); navigate(clean, { replace: true }); } }, []);`
   - Note: Shell already imports `useLocation` from react-router-dom. Need to also import `useNavigate`.

3. **netlify.toml:** Add `[[redirects]]` block for SPA fallback. The existing `public/_redirects` file already has `/* /index.html 200`, but add to `netlify.toml` for explicit config:

```toml
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

Add this block after the `[build.environment]` section (end of file).

Do NOT touch any route definitions, component imports, or JSX structure. Only router import and hash redirect logic.
</action>
