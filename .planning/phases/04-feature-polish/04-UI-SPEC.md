## Interaction Contract

### TeamMemberModal (NEW — requirements TEAM-03, TEAM-04, TEAM-05)

**Trigger:** Click on any team member card in Equipo.jsx.

**Visual spec:**
- Modal overlay: `fixed inset-0 bg-black/80 z-50 flex items-center justify-center p-4`
- Modal container: `bg-white rounded-2xl shadow-2xl max-w-lg w-full max-h-[90vh] overflow-y-auto`
- Close button: top-right, absolute, `text-gray-500 hover:text-gray-800 text-3xl` (× entity), transparent bg
- Layout (top to bottom):
  1. Member photo (if exists): `w-full h-64 object-cover rounded-t-2xl` — or placeholder
  2. Content padding: `p-6 space-y-4`
  3. Name: `text-2xl font-bold text-gray-900`
  4. Role: `text-sm font-semibold text-yellow-600 uppercase tracking-wide`
  5. Full description: `text-base text-gray-700 leading-relaxed` — no truncation
  6. "Hablemos" button: `w-full bg-black text-white px-6 py-3 rounded-lg font-semibold hover:bg-gray-800 transition-colors`
- Click outside modal container (overlay) closes modal — existing pattern from gallery modal

**States:**

| State | Visual | Behavior |
|-------|--------|----------|
| Loading (modal opening) | Skeleton pulse overlay, same layout | Show while fetching full member data (if needed) |
| Loaded | Full modal with all data | Member info displayed, button clickable |
| Error | Simple text error in modal body | "Error al cargar la información del miembro. Intentá de nuevo más tarde." |
| Closed | Modal removed from DOM | Background scroll restored |
| "Hablemos" clicked | Opens default mail client | `window.location.href = mailto:{email}` — no navigation away from page |

### Property Sorting (PROP-01)

**No visual change.** Data order changes from `orderBy('orden', 'desc')` to `orderBy('fechaIngreso', 'desc')` in `usePropiedades.js`. Users see newest properties first. No sort controls needed — single sort direction is sufficient.

### JSON-LD Structured Data (PROP-02)

**Invisible to user.** Script block injected into `<head>` of property detail page. No UI change.

### Code Splitting (PERF-01, PERF-02)

**No visual change.** Existing `Suspense` fallbacks already defined:
- Admin: `<div className="text-center py-20 text-gray-400">Cargando…</div>` — reused pattern
- Blog: uses same pattern as admin (lazy-loaded with `<Suspense>`)

**New lazy imports needed:**
- BlogList + BlogArticle → current import is eager; move to `lazy(() => import(…))`
- Modal.jsx (valuation) → current imports handled in parent; wrap with `lazy`
- TeamMemberModal → lazy-load by default

### Admin Schema Update (TEAM-04)

**Field added to `schemas.js` `nosotros` array:**
```js
{ key: 'email', label: 'Email', type: 'text', required: false }
```

No visual change to admin UI — rendered by existing `AdminForm.jsx` using `TextField` component.
